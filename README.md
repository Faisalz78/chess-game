# ♟️ Chess Game (Desktop App)

A clean and simple **desktop chess game** built using **HTML, CSS, JavaScript**, and packaged as a **Windows desktop application** with **Electron**.

---

## 🎮 Features
- Classic chess gameplay
- Clean and simple UI
- Sound effects for moves and captures
- Desktop application (no browser needed)
- Windows installer (.exe)
